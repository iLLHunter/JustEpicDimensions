# Just Epic Dimensions

A NeoForge mod that adds custom dimensions to Minecraft. You describe each dimension in JSON files or a datapack: terrain, sky and lighting, time and weather, mob spawning, travel, inventories and who may enter. JED loads them as real worlds, and can also create, reset or retire them while the server runs.

- Minecraft 1.21.1, NeoForge 21.1.243 or newer, Java 21.
- Install `justepicdimensions-2.0.0.jar` on both the server and every client. It already contains Arbitrage, JED's required coremod, so there is nothing else to install.

## Making a dimension

Paste [AI_DIMENSION_GUIDE.md](AI_DIMENSION_GUIDE.md) into a chat with an AI assistant and describe the world you want. It asks you a few questions and writes the files for you.
